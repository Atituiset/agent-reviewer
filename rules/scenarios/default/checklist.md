# default · default-review

通用兜底清单：与具体 CWE 无关的基础质量信号（CWE-通用）

## 检测信号
- 变更与其调用方/被调方一致（签名、语义、返回值处理）
- 错误路径存在且错误被传播而非吞掉（空 catch/忽略返回值）
- 获取的资源在所有退出路径上释放（锁/fd/连接/事务）
- 无调试残留（打印、注释掉的代码、临时代码）
- 公共接口行为变化同步了文档/注释

## 安全模式（修复方向）
- （本场景无固定安全模式；finding 的 remediation 由 reviewer 结合上下文给出）

## 输出要求
- 仅报告与本场景检测信号相关的 finding；每条必须带 file:line 与成因一句话
- 无证据不报；置信度 <80 不报
