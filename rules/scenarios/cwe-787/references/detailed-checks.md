# CWE-787 越界读写 评审清单

## 1. 长度从哪来，可信吗

- 长度/大小是否来自外部输入（网络包、文件、IPC、用户参数）？外部长度与缓冲区实际大小的比较是否完备？
- `strlen`/`sizeof` 混用：对指针用 `sizeof` 得到的是指针宽度而非缓冲区大小——高危反模式
- 长度计算中的 `+1`（NUL 终止符、头部、对齐）是否遗漏？

## 2. 拷贝与写入边界

- `strcpy/strcat/sprintf/gets` 等非受限 API：是否可替换为 `snprintf/strncpy` 且**终止符处理正确**？（`strncpy` 不保证 NUL 结尾）
- `memcpy/memmove` 的 size 是否越出源或目的？源目的重叠时误用 `memcpy`？
- 循环写入：边界条件是 `<` 还是 `<=`？off-by-one？

## 3. 读取边界

- 数组/缓冲区下标：下标来源是否可能为负（有符号混用）或 ≥ 长度？
- 解析变长数据（TLV、协议字段）：每步读取前是否校验剩余长度？

## 4. 整数前提

- 长度计算是否可能整数溢出/回绕后绕过边界检查？（联动 cwe-190：`malloc(n*size)` 的乘法溢出）

## 输出要求

报告需给出：写入/读取点 `file:line`、缓冲区大小来源、长度来源、越界成立的具体取值路径。无法构造越界路径的"看着危险"不报。
